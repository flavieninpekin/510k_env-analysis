# 510K: 耦合性论证（coupling thesis）

> 目的：把"这些挑战同时出现、且互相影响"从一句卖点变成**可测量、可证伪**的科学主张。
> 配套代码：`baselines/coupling_probes.py`；原始数据：`runs/coupling_probes_{rule,random}.json`。
> 更新：2026-09-16

---

## 0. 一句话主张（比 draft.md 更锋利）

> 现有 MARL benchmark 让不同难点**各占一个坑位**；510K 让它们**共用同一个决策变量**——
> 一手牌的选择同时改变即时得分、终局进度、关于隐藏队友的信息、以及未来牌型空间。
> 因此"耦合"不是修辞：**它意味着价值函数不可分解**，而这正是现实 agent 面对的结构。

安全性：这不是"510K 最难"，而是**可验证的不可分解性（non-separability）**。

---

## 1. "耦合"的形式定义

设 benchmark 的挑战轴为 `a₁…aₖ`（记分、终局、部分可观测、合作…）。
称这些轴在某环境下**可分离（separable / stacked）**，若存在标量"难度"`D` 与各轴的独立分量使得

```
D(组合) = Σᵢ Dᵢ(aᵢ)        （无交互项；加法可分解）
```

或等价地，最优价值/策略可写成各轴分量的组合。

**510K 的主张：这些交互项非零且可测。** 我们把它拆成 4 条可测量的耦合，每条给出：

- 形式陈述（它为什么使价值不可分解）；
- 为什么现有 benchmark 只有零件、没有这条耦合；
- **可直接计算的签名（signature）**与实测值。

## 2. 四条耦合

### C1 目标纠缠（即时记分 ↔ 终局竞争）

- **形式**：`R = Φ(510K 分数) + Γ(出完名次)`，两项的 argmax 策略不同。
  收分要求**保持出牌权/控牌**（延缓出完），而抢先出完往往要把低牌大牌一起脱手、把分让给对手/队友。
  故 `argmax_π E[分数] ≠ argmax_π E[名次]`，复合目标的最优策略既非二者之一。
- **现有基准**：DouZero（斗地主）只有终局、无随牌记分；普通记分游戏（Hearts/Suphx）无"先出完"的硬竞争。**没有一个把两者放在同一个动作价值里。**
- **签名**：同一局内，"个人得分"与"出完名次"的秩相关；以及"得分最高者是否第一个出完"。
- **实测**（见 §4）：秩相关在所有 mode 下为**负**（rule bot: −0.28 ~ −0.54），
  即收分与抢头名确实互相牺牲；得分王抢到头名的比例 0.38~0.59（随机基线 0.25）。

### C2 合作 × 部分可观测（隐藏队伍是 reward 的隐变量）

- **形式**：DYNAMIC 下 reward 由 deal-time 的隐集合 `T` 决定：
  `R_i = R(o, a; T)`。两个**观测/历史相同**的局面可因 `T` 不同而 reward 映射不同。
  因此部分可观测不是"额外噪声"，而是**合作结构的构成部分**——agent 必须先推断 `T` 才知道自己在优化什么。
- **现有基准**：斗地主/桥牌队伍**固定且已知**（无推断层）；Hanabi 全员队友（无"谁是我队友"）；Avalon/狼人杀有隐藏身份但**无 ground-truth 可训练 RL 基准**。
- **签名**：观测相同、`T` 不同时 reward 的条件方差；以及"自方+队友得分"能解释多少 reward 方差。
- **实测**：`R²(reward ~ own+mate score)` 在 SINGLE 为 0.62~0.79、STATIC 0.64~0.85，
  但在 **DYNAMIC 降到 0.18~0.30**——隐藏关系引入了大量无法从自身+可见队友归因的 reward 方差。

### C3 目标 × 合作（同一个记分目标的"价值"随队伍结构改变）

- **形式**：SINGLE 中 reward 直接含自己的分；团队模式中 reward 聚合两人分并乘以胜负倍数。
  于是**同一个"再收 10 分"这个动作的价值**随合作关系变化：
  `∂R/∂(own score)` 与 `corr(own score, R)` 按 mode 改变。
- **现有基准**：静态队伍游戏里这个系数恒定，无法研究"合作结构如何重塑多目标激励"。
- **签名**：`reward ~ own_score` 回归斜率、`corr(own score, reward)` 的跨 mode 变化。
- **实测**：`corr(own, reward)` 从 SINGLE 的 **0.79~0.89** 跌到团队模式的 **0.42~0.59**；
  斜率则从 1.26~1.49 升到 1.56~2.37（聚合+胜负倍数的非平凡后果）。

### C4 信息 × 合作 × 局面（揭示队友身份的价值是状态依赖的）

- **形式**：`RevealEnv` 以概率 `p` 注入队伍位；其价值 `∂(性能)/∂p` 不是常数，
  而 depend on：是否有队友（1v3 vs 2v2）、当前比分/终局竞赛态势、以及 deal 本身。
- **现有基准**：没有"信息揭示剂量 + 隐藏合作"的可控旋钮，因而无法做这种交互实验。
- **签名**：reveal 收益按队伍规模 / 局面分层后的斜率差；`notes/theory.md` Prop C 已证
  通道近乎线性（`MI(p)` 达理想值 ≥91%），**所以"没收益"不能被解释为"没给信息"**。
- **状态**：需训练策略 → 由正在跑的 1M 矩阵 + `RevealEnv` 提供（见 §6）。

## 3. 为什么"耦合"= 贴近现实（不是为复杂而复杂）

现实 agent（coding agent、谈判 agent、开放环境 agent）恰恰是：
短期收益 + 长期目标 + 其他 agent 意图未知 + 关系动态 + 局面价值不显式。

| 510K 机制 | 现实对应 |
|---|---|
| 记分 × 出完名次 | 立刻让测试通过 vs 不破坏长期架构 |
| 隐藏动态队伍 | "我们此刻是否利益一致"需从行为推断 |
| 信息揭示旋钮 | 新信息到达后，策略是否真的利用（information-utilization gap） |
| 奖励稀释（Prop D） | 团队/组织里贡献与回报不一一对应 |

**关键差异**：这里一切都有 ground truth（真队伍、真分数、真名次），
所以"是否推断对了关系、是否利用了信息"是**可测量**的——这是现实任务给不了、其他社会推理基准也没有的。

## 4. 已测到的耦合签名（本仓库实测）

固定 bot 驱动四个座位，`baselines/coupling_probes.py`，确定性 seed。
`top1st` = 得分最高者最终第一个出完的比例（4 人随机基线 0.25）；
`rho` = 个人得分与出完名次的秩相关（负 = 收分牺牲名次）；
`dR/dOwn` = reward 对个人分数的回归斜率；`R²` = reward 被"自己+队友分数"解释的比例。

**rule bot（n=2000/mode）**

| mode | top1st | rho | 得分王平均名次 | dR/dOwn | corr(own,R) | R²(own+mate) |
|---|---|---|---|---|---|---|
| single | 0.587 | −0.280 | 2.65 | 1.490 | 0.886 | 0.785 |
| static | 0.553 | −0.530 | 1.81 | 2.374 | 0.592 | 0.849 |
| dynamic | 0.570 | −0.544 | 1.87 | 1.954 | 0.531 | **0.300** |
| obvious | 0.376 | −0.358 | 2.32 | 2.124 | 0.570 | **0.338** |

**random bot（n=3000/mode）**

| mode | top1st | rho | 得分王平均名次 | dR/dOwn | corr(own,R) | R²(own+mate) |
|---|---|---|---|---|---|---|
| single | 0.386 | −0.131 | 3.45 | 1.258 | 0.786 | 0.618 |
| static | 0.365 | −0.207 | 2.47 | 1.701 | 0.457 | 0.638 |
| dynamic | 0.374 | −0.228 | 2.49 | 1.559 | 0.416 | **0.179** |
| obvious | 0.374 | −0.228 | 2.49 | 1.559 | 0.416 | **0.179** |

（random bot 下 dynamic≡obvious 属预期：随机 bot 不使用队伍信息，且二者规则/计分完全相同。）

**三条可写进论文的读数**

1. **C1 成立**：`rho < 0` 在所有 mode、两种 bot 下稳定 → 记分与抢名次是**真权衡**，不是可加的两个任务。
2. **C3 成立**：`corr(own,R)` 从 SINGLE 的 0.79~0.89 掉到团队的 0.42~0.59 →
   "同一个记分动作"的激励含义随合作结构改变。
3. **C2 成立**：隐藏队伍模式下 `R²(own+mate)` 腰斩到 0.18~0.34 →
   隐关系贡献了大量**无法归因**的 reward 方差，即"合作推断"不是锦上添花而是核心。

## 5. 这把 benchmark 主张变成研究纲领

| RQ | 由哪条耦合驱动 | 需要的环境能力 | 现有基准能否做 |
|---|---|---|---|
| RQ1 多目标权衡：是否学会"少收分换头名" | C1 | 记分+终局同时开 | 否 |
| RQ2 隐关系推断：能否从出牌推断队友 | C2 | 隐藏动态队伍 + ground truth | 否 |
| RQ3 信息利用缺口：给了队伍信息是否真用 | C4 | 信息揭示旋钮 | 否 |
| RQ4 信用分配：稀释如何解释失败 | C3 | 队友可复现、自身分数可测 | 部分 |
| RQ5 混合动机：策略是否随终局态势切换合作 | C1×C2×C4 | 全部同时 + 可控消融 | 否 |

## 6. 策略级耦合：已测到（1M × 5 seeds，`baselines/analyze_team_conditioning.py`）

环境结构耦合（§4）证明"不可分解"；策略级探针证明"训练出的策略如何应对这些耦合"。
度量：在每个"必须跟牌"的决策上，agent **过牌（不压）** 的概率。
`pLead` = 当前出牌权在**真队友**手上时的过牌率；`pOpp` = 在真对手手上；
`asym = pLead − pOpp` > 0 表示"对队友更礼让"（合作推断的行为签名）。

**MLP PPO, 1M steps, n=1000 局/seed, vs rule bot**

| mode（1M 胜率） | seed | n_decis | pLead | pOpp | asym |
|---|---|---|---|---|---|
| static (0.774) | 0 | 15207 | 0.773 | 0.382 | **+0.391** |
| static | 1 | 15226 | 0.774 | 0.382 | **+0.391** |
| static | 2 | 15648 | 0.771 | 0.426 | **+0.344** |
| static | 3 | 15219 | 0.773 | 0.383 | **+0.390** |
| static | 4 | 15314 | 0.777 | 0.396 | **+0.381** |
| dynamic (0.862) | 0 | 16118 | 0.455 | 0.453 | +0.002 |
| dynamic | 1 | 16099 | 0.463 | 0.457 | +0.006 |
| dynamic | 2 | 15291 | 0.450 | 0.444 | +0.006 |
| dynamic | 3 | 15890 | 0.489 | 0.485 | +0.005 |
| dynamic | 4 | 16050 | 0.514 | 0.519 | −0.004 |
| obvious (0.822) | 0 | 16010 | 0.437 | 0.470 | −0.033 |
| obvious | 1–4 | 15937 | 0.424 | 0.462 | **−0.039** |

**读到的核心发现（比 draft 的"reveal 没用"锋利得多）**

1. **固定且已知的队友 → 策略学会了合作**：STATIC 的 `asym ≈ +0.38`，
   agent 对座位 2 大幅让牌。说明**架构/算法完全有能力学合作**。
2. **隐藏队友 → 完全没有推断出合作**：DYNAMIC 的 `asym ≈ 0.00`。
   agent 的行为**不随真队友变化**——它没有从出牌中推断出"谁是我队友"。
3. **即使把队友身份直接给出（OBVIOUS），仍然不用**：`asym ≈ −0.04`（甚至微反合作），
   且 1M 胜率 **DYNAMIC 0.862 > OBVIOUS 0.822**。
   → 这不是"信息不够"（Prop C 已证通道近线性），而是**策略无法把显式关系转化为合作行为**。
4. **4 个 OBVIOUS seed 在相同发牌上给出几乎逐位相同的决策**（n=15937 全部一致），
   是被训练策略**塌缩到忽略队伍位**的强诊断信号。

**这条链只有 510K 能给出**：同一环境里同时有
(固定已知队友 / 隐藏队友 / 显式给出队友) 三档，且都有 ground truth 可量化行为。
DouDizhu 只有第一档，Hanabi 是"全员队友"，Avalon/狼人杀无 RL ground truth。

**必须写清的 caveat**：跨 mode 的胜率不可直接比较——DYNAMIC/OBVIOUS 的红队由
"持有红 A"定义，隐含更强手牌，胜率被**队伍选择效应**抬高，不全是合作的功劳。
所以论文要以 `asym`/per-agent 指标（而非团队胜率）作为主证据。这正是 `analyze_positions.py` 的用途。

**还差（可选加分）**
- 第二条合作行为通道（不只看过牌，还看"是否喂牌/让分"），排除"合作通过别的通道表达"。
- reveal 中间档 p∈{0.25,0.5,0.75}（需 `RevealEnv` 重训，当前只有 p=0/1）。
- value 侧证据：V 是否随真队伍变化（当前只有行为侧）。

## 7. 给 reviewer 的安全措辞（避免被打）

- ✅ "510K *couples* scoring, terminal competition, partial observability and hidden
  cooperation in a single decision process; we show the couplings are measurable and
  non-separable (§4)."
- ✅ "It is not the hardest card game; it is a *controllable instrument* for studying
  how these challenges alter each other's value."
- ❌ 不说 "more realistic than poker/bridge/DouDizhu"（不可证、易被攻击）。
- ❌ 不说 "hardest"；用 "jointly controlled / ablatable"。
- 预判质疑：
  - "记分与胜负的张力不是常识吗？" → 常识，但**没有基准把它与终局竞争、隐藏合作同时开放并量化**（§4 表）。
  - "团队模式 reward 依赖队友不显然吗？" → 不显然的是**量化后的不可归因比例**（R² 0.18~0.34）与可复现性。
  - "和 IIGC 重复？" → 本文是**环境/耦合表征**，IIGC 是**现象**；C4 是连接二者的接口。
